Internal map model · connected resource clusters · symmetric sectors · size-matched SWD

Resources per Player

All resource groups use the same connected-shape generator. Sliders set the number of tiles; the final column sets the number of clusters. For lakes, the slider specifies tiles per lake.

ResourceTilesClusters

Wildlife is placed in forests. Headquarters and mine construction areas remain protected.

The preview and balance table are derived from the final SWD data. Lakes and deposits are copied from one source sector while preserving tile counts and connectivity. Three- and six-player maps use local hex rotations; five-player maps require rasterization repair. Export uses SWD, not native S2M.

Map Settings

Starting position angular deviation: ±10% of the sector angle (e.g., ±6° for 6 players).

Additional rings of mountain texture around mineral deposits. 0 = no expansion.

SWD dimensions match the size slider. Maps for 2/4 players have even dimensions and square layouts. Maps for 3/5/6 players have odd dimensions, a central tile, and an outer mountain belt.

Resource Variants

Fixed terrain, editable mineral assignments

Each column represents one cluster in the source sector. Copy a row to create a variant, then select it to apply resource assignments to the entire map. Edit the tile count and resource type for each cluster.

Each cluster has a fixed maximum size determined by its generated connected mask. Increasing beyond that capacity requires a new layout. Surface stone and mined granite require different ground types and cannot be swapped directly.
